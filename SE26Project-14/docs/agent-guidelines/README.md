# BioNote 第一阶段 MVP：Code Agent 执行指南

本目录是一组按顺序执行的开发指南，用于让 code agent 在现有 `frontend/` 静态页面基础上，完成可真实演示、可验收的第一阶段 MVP。

## 使用方式

每次只交给 code agent 一份“开发批次”指南。不要一次性要求 agent 完成全部批次。

每个批次开始前，agent 必须完整阅读：

1. `docs/01-product-overview.md`
2. `docs/agent-guidelines/00-master-contract.md`
3. `docs/agent-guidelines/01-domain-api-contract.md`
4. 当前批次指南

只有当前批次明确要求时，才允许读取两个参考项目中的指定文件。禁止把参考项目当作通用代码来源。

## 执行顺序

| 顺序 | 指南                                        | 交付结果                                            |
| ---- | ------------------------------------------- | --------------------------------------------------- |
| 0    | `00-master-contract.md`                     | 全局范围、架构、参考边界和工作纪律                  |
| 0    | `01-domain-api-contract.md`                 | 统一领域模型、状态机、权限和 API 契约               |
| 1    | `02-foundation-auth-profile.md`             | 后端骨架、数据库、认证、注册登录、个人资料          |
| 2    | `03-project-team-invitation.md`             | 项目、成员、邀请、角色变更、归档基础能力            |
| 3    | `04-template-record-authoring.md`           | 系统/个人模板、记录创建、富文本编辑、软删除         |
| 4    | `05-review-attachment-export.md`            | 提交快照、审核闭环、附件上传预览、PDF/Markdown 导出 |

批次必须串行执行。上一批次的验收命令和人工验收项未通过，不得开始下一批次。

## 给 code agent 的推荐开场指令

```text
请严格执行 docs/agent-guidelines/README.md 中的阅读顺序，并完成
docs/agent-guidelines/XX-*.md 对应批次。

要求：
- 先检查当前工作区，不覆盖用户已有修改。
- 只完成本批次范围，不提前实现后续批次。
- 所有后端权限必须真实校验，不能只隐藏前端按钮。
- 完成代码、迁移、测试和文档，并运行本批次验收命令。
- 最后报告修改文件、测试结果、剩余风险；不要只给方案。
```

## 总体验收终点

全部批次完成后，必须能够使用三个真实账号完成以下闭环：

1. A、B、C 分别注册并使用邮箱登录。
2. A 创建项目并邀请 B、C；B、C 在通知中接受。
3. A 将 C 调整为审核者。
4. B 使用个人或系统模板创建记录、保存富文本正文并上传附件。
5. B 提交给 C，生成不可变 `R1`；C 退回并填写意见。
6. B 修改后再次提交生成 `R2`；C 审核通过，记录永久只读。
7. 项目成员可预览图片/PDF附件；无权用户不可通过 URL 下载或预览。
8. 已完成记录可导出中文正常显示的 PDF 和 Markdown；未完成记录不可导出。
9. 全局搜索仅返回当前用户有权访问的内容，并支持筛选和分页。
10. A 仅在所有有效记录完成后才能归档项目；归档后项目只读且不可恢复。
11. 关键操作生成通知和不可修改的审计事件。
